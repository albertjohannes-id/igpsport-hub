# antislop audit 001, 22 October 2026

Scope: current UI source (src/App.tsx, src/components.tsx, src/style.css, index.html) as of commit `a9ba5fb`. Direction reference: docs/UI-REVIEW.md (ENERGY 1 / RHYTHM 2 / MOTION 1, teal accent, system type, Albert's request for minimal/modern/lightweight/mobile-friendly).

## Findings

### 1. R-02 HIGH: em dashes in interface copy

src/App.tsx lines 487, 698, 1136, 1140, 1144, 1148, 1153. The home callout, the Garmin-prompt callout, and the How-to modal use the em dash character (`—`) inside prose. The 18 October UI review explicitly passed R-02 with "prose uses regular punctuation"; the copy added in this session reintroduced it.
Reason: an em dash in text is banned by R-02; replace with commas, colons, or parentheses.

### 2. R-38 HIGH: false claim of where credentials go

src/App.tsx line 965 (login dialog note): "Credentials are sent through the local app to iGPSPORT/Garmin." This is shown on every deployment, including the hosted Vercel app, where credentials go to the hosted backend, not a local app.
Reason: R-38 / C-5: claims must match reality; show the deployment-accurate sentence instead.

### 3. R-25 MEDIUM: disconnected dot below 3:1

src/style.css `.dot.disconnected` uses `#c98a2b`, 2.94:1 on white (also used in dark mode). Non-text UI indicators need 3:1, and the amber dot is the "Not connected" signal in tab and card.
Reason: a status dot that is nearly invisible against the surface fails R-25's contrast floor; darken ~1 step.

### 4. R-03 MEDIUM (re-verify): 320px overflow after the layout change

The 18 October review verified overflow checks at 320/390/768/1280px, but the October session changes (sidebar removed, horizontal tab row, callout, step chips, how-to hint) were regression-tested at 768/1280 only. Not a proven violation; must be re-run at 320/390 in both themes before it can be marked PASS again.
Reason: R-03 requires the mobile layout to be verified where UI structure changed.

## Improvement candidates (no rule broken, UX picks)

### 5. Unsized quick win: filter to unsynced rides

The iGPSPORT table mixes never-transferred rides with synced/checked ones. A small "Show only unsynced" toggle in the toolbar reduces the scan for repeat users.

### 6. Bulk select shortcut

No "select all unsynced on this page" control; rides must be ticked one at a time. A single text link beside the count would cut the steps to send a batch.

### 7. Unconfirmed result needs the follow-up button inline

When a transfer ends in "Upload received, but not yet confirmed", the result banner explains it, but the "Check status" action lives only in the Recent transfers list below. Putting the same Check status button inside the result banner removes the hunting step.

### 8. Version hidden on phones

The topbar version (`v0.1.0`) is display:none under 760px (`.environment`), and the home footer is the only place it is visible on a phone. Keep topbar version visible on mobile or accept it as deliberate.
